# Retro Synth

A cross-platform Python desktop workstation for composing and previewing retro game music in real time, using FM, PCM, and wavetable synthesis models associated with 16-bit-era hardware, and exporting the result as modern audio files.

## Installation

```bash
cd retro_synth
pip install -e .[dev]
```

## Running

```bash
retro-synth
```
